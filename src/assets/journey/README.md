# Journey scene assets

Drop files here and the homepage journey picks them up automatically —
no code change. Same mechanism as src/assets/renders/.

    server.png   (or .jpg / .webp / .avif)   a real server or rack
    mobile.png                                mobile accessories

Until a file exists, that item rides the flow as a label chip instead of
an empty frame. Transparent PNG suits the composite best; ~1200px wide is
plenty, since it renders at roughly 200px.
